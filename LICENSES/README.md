# Third-party licenses

This directory holds license attribution for code that is **not** pulled in as
a Rust crate dependency (and therefore is not generated by `cargo about`).
Downstream binary distributions (VST, AU, standalone installers) should bundle
both:

1. The auto-generated `third_party_licenses.html` from `cargo about generate
   about.hbs`, which covers every Rust crate in `Cargo.lock`.
2. The files in this directory, which cover SDKs, headers, or code that is
   integrated outside the Cargo dependency tree.

## Files

- `VST_SDK.md` — Steinberg VST 3 SDK. MIT-licensed. Required attribution if a
  distribution links against the VST 3 headers or libraries, even though the
  SDK itself is not part of this repository.

## Adding a new attribution

1. Create a new `<NAME>.md` in this directory with the full license text and
   copyright notice.
2. Add a one-line description to the "Files" section above.
3. If the attribution applies to a binary build, make sure the build pipeline
   includes the file alongside `third_party_licenses.html`.
